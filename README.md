# Tower Stack Game



A simple Unity game where you stack blocks to build the tallest tower possible.



## Features



- Block stacking gameplay

- Score and high score system

- Dynamic camera movement

- Sound effects

- Background music

- Simple arcade mechanics



## Technologies



- Unity

- C#



## Controls



| Action | Key |

| --- | --- |

| Drop Block | Space |

| Pause | P/Esc |
